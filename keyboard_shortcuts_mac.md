# macOS Keyboard Shortcuts

This document lists all macOS-optimized keyboard shortcuts for the Restaurant Billing Application. These shortcuts are mapped to standard macOS modifier keys: `⌘ Command` (Command), `⌥ Option` (Option/Alt), `⇧ Shift` (Shift), and standard function keys.

---

## 🌐 Global Navigation

Use these shortcuts from any screen to jump between tabs:

*   **⌥ Option + 1**: Go to **Billing Screen**
*   **⌥ Option + 2**: Go to **Recent Bills**
*   **⌥ Option + 3**: Go to **Shifts**
*   **⌥ Option + 4**: Go to **Food Menu**
*   **⌥ Option + 5**: Go to **Admin Panel** (Admin only)

---

## 🛡️ Admin Panel Navigation (Admin Only)

When in the Admin Panel, jump directly to specific tabs using:

*   **⌘ Command + ⌥ Option + 1**: Dashboard
*   **⌘ Command + ⌥ Option + 2**: Reports
*   **⌘ Command + ⌥ Option + 3**: Reconciliation
*   **⌘ Command + ⌥ Option + 4**: Settings
*   **⌘ Command + ⌥ Option + 5**: Split Bill Settings
*   **⌘ Command + ⌥ Option + 6**: Track Control
*   **⌘ Command + ⌥ Option + 7**: Purge Bills (Danger Zone)

---

## 📊 Report Screen Shortcuts (Admin Only)

Within the Admin Reports sub-tabs:

*   **⌘ Command + ⇧ Shift + 1**: Time Range Report
*   **⌘ Command + ⇧ Shift + 2**: Date Range Report
*   *Note: Reports 3 (Shift Report) and 4 (Item Report) are disabled for `⌘ Command + ⇧ Shift` on macOS to prevent conflicts with native macOS screenshot shortcuts (`⌘ + ⇧ + 3`, `⌘ + ⇧ + 4`). On non-Mac systems, `Ctrl + Shift + 3` and `Ctrl + Shift + 4` remain functional.*

---

## 🧾 Billing Screen Shortcuts

*   **F1** or **⌘ Command + 1** or **⌥ Option + 1**: Open Help Panel (Search Menu Items)
*   **F2** or **⌘ Command + 2** or **⌥ Option + 2**: Open Active Bills Popup
*   **F4** or **⌘ Command + 4** or **⌥ Option + 4**: Toggle Shortcuts & Active Bills Popup
*   **F3** or **⌘ Command + 3** or **⌥ Option + 3**: Toggle Split Bill Mode
*   **⌘ Command + D** or **⌥ Option + D** (or **PageDown**): Move focus to **Item Code** input
*   **⌘ Command + Enter** or **⌘ Command + P** (or **End** / **Home**): Finalize and print the bill
*   **⌘ Command + F**: Open Help Panel (Search Menu Items)
*   **Escape (Esc)**:
    *   Close Help/Shortcuts Popup
    *   Return focus to **Table Number** field (if cursor is in Item Code)
    *   Cancel Quantity Edit
*   **Table Number Input**:
    *   **Enter** or **Tab**: Load table data and move to **Party Number**
*   **Party Number Input**:
    *   **Enter** or **Tab**: Move directly to **Item Code** (skipping Section field)
*   **Item Code Input**:
    *   **ArrowDown (↓)**: Move focus to the first bill item row
    *   **Enter**: Add the item to the bill
*   **Bill Items (Grid)**:
    *   **ArrowUp (↑) / ArrowDown (↓)**: Navigate between rows
    *   **Enter**: Edit Quantity for the selected row
*   **Quantity Input (Edit Mode)**:
    *   **Enter**: Save quantity and return to **Item Code**
    *   **Escape (Esc)**: Cancel edit and return to **Item Code**

---

## 📋 Recent Bills Screen

*   **ArrowUp (↑) / ArrowDown (↓)**: Navigate through the bills list
*   **Enter** or **Space**: Expand/Collapse selected bill details
*   **F3** or **⌥ Option + S** or **⌘ Command + S**: Focus search box
*   **Escape (Esc)**: Clear search term

---

## 🍽️ Food Menu Screen

*   **⌘ Command + F**: Focus Search Box
*   **⌥ Option + S** or **⌘ Command + S**: Focus Search Box
